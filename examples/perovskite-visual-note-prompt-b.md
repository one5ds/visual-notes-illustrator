# 案例 B：同一段文字，换一个主体 —— 阶梯金字塔

> **为什么有第二个案例**：本 Skill 的核心承诺是「每次创作的主体都不同」。
> 案例 A 选了 **沙漏引擎**（筛选隐喻），案例 B 选了 **阶梯金字塔**（能级阶梯隐喻）。
> 底本、主标题、信息分区完全一样，只有核心主体和隐藏纹样变了 —— 出来的完全是两张图。

- 底本：钙钛矿「可调门槛」科普段落（同案例 A）

- 画幅：9:16 竖版 / 1024×1536
- 隐藏纹样：阿拉伯几何纹（案例 A 用的是中国回纹）

## 一、完整提示词（可直接粘给豆包 / 即梦）

请生成一张 9:16 竖版（1024×1536）的学院派手绘视觉笔记插画。

【主标题】画面顶部居中，粗衬线印刷体双语：
「钙钛矿：唯一能把『门槛』调出来的光伏材料」
「PEROVSKITE: THE MATERIAL WITH A TUNABLE THRESHOLD」

【核心主体】画面视觉中心：一座**剖开的阶梯金字塔**——每一级台阶都装有螺旋升降机构与滑杆，台阶高度可连续调节，台阶侧面标注刻度 **1.2 → 3.0 eV**；塔身纵向剖开，露出内部能级阶梯与光子粒子沿台阶逐级跃迁的轨迹箭头；金字塔底部并列两块固定不可调的对照台阶，标注 **Si 1.12 eV** 与 **GaAs 1.42 eV** 并打叉标记；塔顶悬浮一卷可弯折卷起的超薄柔性薄膜片，标注厚度 **d ≈ 0.5 μm**（发丝 1/100）；塔体表面密布晶格缺陷小点，旁边标注 V_oc 依然很高。
- 主体四周环绕 4 个小型设计草图：正视图、侧视图、45° 俯视图、爆炸分解图，简洁线条 + 铅笔排线阴影，标注关键尺寸与数据。
- 机械制图标注：尺寸线、双向箭头、角度弧线、坐标轴、向量箭头、剖面符号。

【信息分区】双语印刷体短标签 + 指引线：
① 门槛出厂焊死 / FIXED THRESHOLD
② 卤素配比 / HALIDE RATIO —— I·Br·Cl 配比旋钮对应 1.2–3.0 eV 滑杆
③ 量体裁衣叠层 / TANDEM MATCH
④ 极薄柔性 / ULTRA-THIN & FLEXIBLE —— d ≈ 0.5 μm
⑤ 缺陷容忍 / DEFECT TOLERANCE

【画布与底色】纯白主色，极淡 5mm 打印方格纸网格，四周不留深色底图。

【线条与质感】HB/2B 铅笔素描干练线条，阴影用排线与交叉排线。

【学术公式】ABX₃；E_g = 1.2–3.0 eV；E_g(Si) = 1.12 eV；E_g(GaAs) = 1.42 eV；λ = 1240/E_g (nm)；d ≈ 0.5 μm；V_oc；η

【色彩】黑白灰为主，台阶 eV 刻度条、卤素 I/Br/Cl 色点、叠层淡色带用低饱和马克笔平涂，彩色面积 < 12%。

【手写批注】5 处：「出厂焊死 vs 随配方变」「台阶高度连续可调 1.2–3.0 eV」「0.5μm＝发丝 1/100」「不用高温真空，可印刷」「缺陷多也不掉电压」

【学院派细节】便签贴、回形针、胶带痕、页边编号、装订孔、红色批阅笔迹。

【隐藏纹样】极淡的**阿拉伯几何纹**作底纹，不抢主体。

【排版】内容充满画幅，严格网格对齐。

【负向提示】不要真人、不要 3D 渲染质感、不要霓虹渐变、不要大面积深色背景、不要与主题无关的词语、不要错别字、不要水印。

9:16 竖版学院派手绘视觉笔记：白底方格纸上铅笔素描的「剖开阶梯金字塔」，每级台阶带升降滑杆与 1.2–3.0 eV 刻度，底部并列 Si 1.12 / GaAs 1.42 打叉固定台阶，塔顶悬浮 0.5 μm 可卷曲薄膜；四周四组草图与尺寸标注；含 ABX₃、E_g、λ=1240/E_g 公式，双语标签，淡彩马克笔色条，手写中文批注，便签贴，隐约阿拉伯几何纹底纹。

## 三、A / B 对照：同一个底本能差多少

| 维度 | 案例 A | 案例 B |
|---|---|---|
| 底本文字 | 钙钛矿「可调门槛」 | 完全相同 |
| 主标题 | 完全相同 | 完全相同 |
| 核心主体 | 沙漏引擎 | 阶梯金字塔 |
| 隐喻逻辑 | 光子穿过阀门被**筛选** | 台阶高度被**调高调低** |
| 带隙的表达 | 阀门开口大小 | 每级台阶的升降高度 |
| 隐藏纹样 | 中国回纹 | 阿拉伯几何纹 |
| 视觉重心 | 中间腰部（节流点） | 纵向堆叠（阶梯阵列） |
| 出图风格 | 机械腔体、粒子流 | 建筑体块、剖面层级 |

**结论**：换主体 = 换隐喻 = 换整张图的叙事结构，而标题与信息分区可以原封不动。这正是 Skill 里「20 选 1」这一步的价值。
